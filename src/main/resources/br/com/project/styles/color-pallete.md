

# CORES GERAIS

## 🔵 Azul Principal — `#1E3A8A`
**(é)**

- Função: Identidade e estrutura

- Usar em Barra superior (TopBar); Menu lateral; Cabeçalhos de telas; Botões principais (ex: “Finalizar Venda”); Títulos de seções

## 🔷 Azul Secundário — `#3B82F6`
**(comunica “ação disponível”)**

- Função: Interação

- Usar em: Botões secundários (Salvar, Editar, Confirmar); Hover de botões; Links; Campos selecionados; Indicadores de foco (focus ring)

## 🟢 Verde *Ação/Status Positivo* — `#16A34A`
**(⚠️ Não usar em botão padrão, deve indicar resultado positivo, não ação comum)**

- Função: Confirmação e sucesso

- Use em: Status “Entrega Concluída”; “Pagamento Aprovado”; “Estoque OK”; Toast de sucesso; Ícones de check

## ⚪ Cinza Claro *Fundo* — `#F3F4F6`

- Função: Base da interface

- Use em: Fundo principal da aplicação; Cards; Containers; Áreas de listagem

## ⚫ Cinza Escuro *Texto* — `#1F2937`
**(Nunca usar azul para texto comum, texto precisa ser neutro e legível.)**

- Função: Texto principal

- Use em: Textos normais; Labels; Informações de produto; Valores monetários

# CORES DE ESTADO

## 🔴 Erro — `#DC2626`

- Use em: Pagamento recusado; Produto sem estoque; Campos inválidos; Alertas críticos

## 🟡 Aviso — `#F59E0B`

- Use em: Estoque baixo; Entrega atrasada; Pendência financeira

# 📦 Aplicação Prática por Tela
Tela de Venda (Caixa)

* TopBar → Azul Principal

* Botão “Finalizar Venda” → Azul Principal

* Botão “Cancelar” → Cinza médio

* Pagamento aprovado → Verde

* Pagamento recusado → Vermelho

Tela de Entregas

* Status “Em rota” → Azul Secundário

* Status “Concluída” → Verde

* Status “Atrasada” → Amarelo

* Status “Cancelada” → Vermelho

Tela de Estoque

* Quantidade normal → Texto padrão

* Estoque baixo → Amarelo

* Produto esgotado → Vermelho
